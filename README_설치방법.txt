수처작주 입처개진 PWA v4.4.9 설치방법

[기존 GitHub Pages 앱 업데이트]
1. 압축파일을 풉니다.
2. 압축을 푼 폴더 안의 파일 전체를 기존 GitHub 저장소 최상위에 업로드합니다.
3. 같은 이름의 기존 파일은 새 파일로 교체합니다.
4. Commit changes를 누릅니다.
5. 1~3분 후 휴대폰 Chrome에서 기존 앱 주소를 엽니다.
6. 새로고침한 뒤 설치된 앱을 완전히 종료하고 다시 실행합니다.

[처음 설치]
1. GitHub Pages 주소를 휴대폰 Chrome에서 엽니다.
2. 오른쪽 위 점 3개 → 앱 설치 또는 홈 화면에 추가를 누릅니다.
3. 설치를 누르면 바탕화면에 앱 아이콘이 생성됩니다.

[기록 유지]
- 기존과 동일한 GitHub Pages 주소에 덮어쓰면 기존 저장 데이터가 유지됩니다.
- 다른 저장소나 다른 주소에 올리면 저장 공간이 달라져 기록이 자동 이전되지 않습니다.
- 주소를 바꿀 때는 기존 앱의 설정에서 데이터를 내보낸 후 새 앱에서 가져오세요.

[업데이트가 안 보일 때]
- Chrome에서 웹 주소를 직접 열어 새로고침합니다.
- 설치된 앱을 완전히 종료하고 다시 실행합니다.
- 저장 데이터 삭제는 기록을 지울 수 있으므로 하지 마세요.
