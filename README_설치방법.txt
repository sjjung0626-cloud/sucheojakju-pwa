수처작주 입처개진 PWA v4.5.0

[기존 GitHub Pages 앱 업데이트]

1. 이 ZIP 파일을 PC에서 압축 해제합니다.
2. 압축을 푼 폴더 안의 파일과 icons 폴더 전체를 기존 GitHub 저장소 최상위에 업로드합니다.
3. 같은 이름의 기존 파일은 새 파일로 교체합니다.
4. Commit changes를 누릅니다.
5. 1~3분 기다린 뒤 휴대폰 Chrome에서 기존 사이트 주소를 엽니다.
6. 새로고침합니다.
7. 설치된 앱을 완전히 종료한 뒤 다시 실행합니다.

[처음 설치]

1. GitHub Pages 주소를 휴대폰 Chrome에서 엽니다.
2. 오른쪽 위 점 3개를 누릅니다.
3. 앱 설치 또는 홈 화면에 추가를 선택합니다.
4. 설치를 누르면 바탕화면에 앱 아이콘이 생성됩니다.

[기록 유지]

- 기존과 동일한 GitHub Pages 주소에 덮어쓰면 저장 데이터는 유지됩니다.
- 저장 키 sucheojakju_v1을 그대로 사용합니다.
- 다른 저장소나 다른 주소에 배포하면 기존 기록이 자동 이전되지 않습니다.

[이번 버전]

- 원칙 관리창 최종 저장 버튼 추가
- 최종 저장 후 '저장되었습니다.' 메시지 표시
- 원칙 관리와 오늘 원칙·마무리·내일 작은 행동 드롭다운 동기화
- 기존 원칙·일정·습관 기록 유지
