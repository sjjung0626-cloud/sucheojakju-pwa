수처작주 입처개진 PWA v4.5.4

[이번 버전의 핵심]
- HTML v4.5.4 최종 내용 기준
- 매월 여러 날짜 반복 선택
  예: 매월 1일·15일·28일
- 매월 같은 순번의 여러 요일 선택
  예: 매월 세 번째 월·수·금요일
- 하단 탭 순서
  오늘 → 정체성 → 습관 → 멈출 행동 → 흔들릴 때
- 좌우 화면 밀기로 탭 이동
- 기존 원칙·습관·멈출 행동·일정·날짜별 기록 유지

[기존 GitHub Pages 앱 업데이트]
1. ZIP 파일을 PC에서 압축 해제합니다.
2. 압축을 푼 폴더 안의 파일과 icons 폴더 전체를 기존 GitHub 저장소 최상위에 업로드합니다.
3. 같은 이름의 기존 파일은 새 파일로 교체합니다.
4. Commit changes를 누릅니다.
5. 1~3분 기다립니다.
6. 휴대폰 Chrome에서 기존 GitHub Pages 주소를 직접 엽니다.
7. 새로고침합니다.
8. 설치된 앱을 완전히 종료한 뒤 다시 실행합니다.

[처음 설치]
1. GitHub Pages 주소를 휴대폰 Chrome에서 엽니다.
2. 오른쪽 위 점 3개를 누릅니다.
3. '앱 설치' 또는 '홈 화면에 추가'를 누릅니다.
4. 설치를 누르면 휴대폰 바탕화면에 앱 아이콘이 생성됩니다.

[기록 유지]
- 반드시 기존과 같은 GitHub Pages 주소에 업데이트하세요.
- 저장 키 sucheojakju_v1을 그대로 사용하므로 같은 주소에서는 기존 기록이 유지됩니다.
- 새 저장소나 다른 주소에 배포하면 브라우저 저장공간이 달라져 기록이 자동 이전되지 않습니다.
- 사이트 데이터 삭제는 기존 기록을 지울 수 있으므로 하지 마세요.
