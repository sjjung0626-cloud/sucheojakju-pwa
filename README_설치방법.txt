수처작주 입처개진 PWA v4.1.3

중요
- 이 ZIP을 휴대폰에서 직접 열어서는 PWA로 설치되지 않습니다.
- PWA는 반드시 HTTPS 주소에서 실행해야 합니다.

가장 쉬운 배포 방법: Netlify
1. 이 ZIP을 압축 해제합니다.
2. Netlify Drop 페이지에서 압축을 푼 sucheojakju_pwa_v4_1_3 폴더를 업로드합니다.
3. 생성된 https:// 주소를 휴대폰 Chrome 또는 Samsung Internet으로 엽니다.
4. 브라우저 메뉴에서 '앱 설치' 또는 '홈 화면에 추가'를 선택합니다.

GitHub Pages
1. 새 GitHub 저장소를 만듭니다.
2. 이 폴더 안의 파일 전체를 저장소 최상위에 올립니다.
3. Settings → Pages → Deploy from a branch → main / root를 선택합니다.
4. 생성된 HTTPS 주소로 접속해 설치합니다.

포함 파일
- index.html: 앱 본체
- manifest.webmanifest: 설치 정보
- sw.js: 오프라인 실행
- icons/: 앱 아이콘
- 404.html: 정적 호스팅 경로 보완
- netlify.toml, _headers: Netlify 설정

데이터 저장
- 날짜별 기록은 설치한 브라우저/PWA 저장공간에 보관됩니다.
- 브라우저 데이터 삭제, PWA 데이터 삭제 시 기록이 사라질 수 있습니다.
- 중요한 기록은 앱의 데이터 내보내기로 백업하세요.
